# عقود — منصة إنشاء العقود الإلكترونية

منصة بسيطة وسريعة لإنشاء عقود إلكترونية بالعربية. مناسبة للاجتماعات والاستخدام السريع مع الآخرين.

## الفكرة
- تدخل البنود الأساسية (الأطراف، القيمة، التاريخ، التفاصيل).
- تختار نوع العقد (بيع، خدمات، إيجار، شراكة، اتفاق عام...).
- تعاين العقد وتعدّل البنود مباشرة في المعاينة.
- تصدر العقد كـ PDF أو تطبعه.
- تحفظ العقود محلياً في المتصفح (قاعدة بيانات بسيطة).
- الصفحة قابلة للمشاركة مع الآخرين للتعديل والاقتراحات.

## الملف الرئيسي
- `Contracts.html` — النسخة المحسّنة (مع اختيار نوع العقد والتعديل المباشر)

## كيف تستخدمه
1. افتح ملف `Contracts.html` في المتصفح (Chrome أو Safari أو Edge).
2. اختر نوع العقد واملأ البيانات الأساسية.
3. اضغط «معاينة العقد» ثم عدّل النص مباشرة إذا أردت.
4. حمّل كـ PDF أو اطبع.
5. يمكنك حفظ العقد محلياً للرجوع إليها لاحقاً.

## ملاحظات
- التخزين المحلي يعتمد على LocalStorage في المتصفح (يختفي عند مسح بيانات المتصفح).
- تكامل Google Drive موجود في الكود لكن يحتاج إعداد Client ID حقيقي من Google Cloud.
- يمكن نشر الصفحة على GitHub Pages أو Netlify للمشاركة السهلة مع الآخرين.
